一、 Watch（觀察及紀錄）

1. 影片中提到，傳統軟體安裝常遇到環境衝突，Docker 主要想解決什麼「部署問題」？[cite: 1]

💬 卡住時問AI老師

請參考以下選項（點擊可直接帶入輸入框）：

👉 **(A)** 安裝軟體時常因作業系統相依性或套件版本不同而導致「在我電腦可以跑，別人電腦不行」的衝突[cite: 1]。

👉 **(B)** 電腦硬碟空間不足，無法安裝大型軟體。

👉 **(C)** 網路連線速度太慢，導致軟體下載失敗。

2. 影片中如何比喻並區分什麼是 Image（映像檔） 與 Container（容器）？[cite: 1]

💬 卡住時問AI老師

請參考以下選項（點擊可直接帶入輸入框）：

👉 **(A)** Image 像是「毛胚屋/建築設計圖」，Container 像是「實際入住且可供使用的房子/執行的實例」[cite: 1]。

👉 **(B)** Image 是硬體設備，Container 是驅動程式。

👉 **(C)** Image 是系統備份檔，Container 是電腦病毒。

3. 在執行 docker run -d -p 8080:80 nginx 時，參數 -d 與 -p 各自代表什麼意義？[cite: 1]

💬 卡住時問AI老師

請參考以下選項（點擊可直接帶入輸入框）：

👉 **(A)** -d 表示在背景執行（Detached mode），-p 表示將本機的連接埠對應到容器內的連接埠[cite: 1]。

👉 **(B)** -d 表示刪除容器（Delete），-p 表示暫停容器（Pause）。

👉 **(C)** -d 表示下載映像檔（Download），-p 表示列出程序（Process）。

4. Docker 和傳統「虛擬機（VM）」在系統資源佔用與架構上有何關鍵差異？[cite: 1]

💬 卡住時問AI老師

請參考以下選項（點擊可直接帶入輸入框）：

👉 **(A)** 虛擬機需要模擬完整的作業系統，耗費較多資源；Docker 共用宿主機的作業系統核心，輕量且啟動極快[cite: 1]。

👉 **(B)** Docker 必須安裝在虛擬機裡面才能運作。

👉 **(C)** 虛擬機不需要任何作業系統，而 Docker 需要雙倍作業系統。
