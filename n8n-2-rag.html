一、 Watch（觀察及紀錄）

1. 什麼是本地端 LLM？相較於雲端大型語言模型，本地端在處理商店顧客資料或私有文件時有何優點？[cite: 7]

💬 卡住時問AI老師

請參考以下多維度正確選項（點擊可直接帶入輸入框）：[cite: 7]

👉 **(A) 【資料隱私切入】** 所有資料與顧客對話皆留在本機運行，不會上傳至第三方雲端伺服器，能完美保護商店敏感商業機密與顧客個資[cite: 7]。

👉 **(B) 【自主控制切入】** 不需要依賴外部網路連線或付費 API 額度，只要本地硬體（如顯示卡）足夠，就能不受限制地 24 小時自主運行[cite: 7]。

👉 **(C) 【離線辦公比喻切入】** 就像是在自己家裡設立一間「完全保密的獨立檔案室」，所有帳冊與機密文件都不用外送給別人保管，安全係數最高[cite: 7]。

2. 什麼是 AI 的「幻覺」？為什麼需要導入 RAG（檢索增強生成）技術來改善？[cite: 7]

💬 卡住時問AI老師

請參考以下多維度正確選項（點擊可直接帶入輸入框）：[cite: 7]

👉 **(A) 【技術原理切入】** AI 幻覺是指模型在缺乏正確資訊時會「一本正經地胡說八道」；導入 RAG 就像是考試時允許 AI「開書考（帶講義進場）」，根據檢索到的真實文件來生成精確回答[cite: 7]。

👉 **(B) 【生活化比喻切入】** 就像店員面對客人詢問退貨政策時，如果憑記憶瞎猜容易出錯；RAG 就像是讓店員手裡拿著最新版的「官方商品與退換貨手冊」照本宣科[cite: 7]。

👉 **(C) 【知識增強切入】** 純 LLM 的記憶受限於訓練時的資料；RAG 透過外掛向量知識庫，讓模型能夠動態存取商店最新、最私有的專屬資料[cite: 7]。

3. 在建立商店知識庫時，為什麼需要將文件進行 Chunk（切片） 與 Embedding（向量化矩陣）？[cite: 7]

💬 卡住時問AI老師

請參考以下多維度正確選項（點擊可直接帶入輸入框）：[cite: 7]

👉 **(A) 【資料處理切入】** 大型文件無法一次塞給 AI，必須切割成適當大小的片段（Chunk），並透過 Embedding 轉成具備語意關聯的數字向量矩陣，以利後續電腦進行數學相似度比對[cite: 7]。

👉 **(B) 【圖書館比喻切入】** 就像是把厚厚一本商店規章拆成一本一本精準的小手冊，並為每一頁編上「關鍵字索引卡」，當客人問問題時才能瞬間找到對應頁面[cite: 7]。

👉 **(C) 【語意理解切入】** 向量化（Embedding）能讓電腦理解字詞背後的意思（例如「退貨」和「換貨」語意相近），而不只是死板地對照文字表面[cite: 7]。

4. 影片中，使用者提問後，系統是如何在向量資料庫中進行相似度比對與檢索（Retrieval）的？[cite: 7]

💬 卡住時問AI老師

請參考以下多維度正確選項（點擊可直接帶入輸入框）：[cite: 7]

👉 **(A) 【數學檢索切入】** 系統會把使用者的提問也轉成同維度的向量，透過計算向量之間的夾角或距離（如餘弦相似度），從資料庫中找出最相關的幾個 Chunk 片段[cite: 7]。

👉 **(B) 【尋寶雷達比喻切入】** 就像拿著客人的問題當作雷達波，在向量資料庫的座標地圖中掃描，精準定位出距離最近、最符合答案的知識寶箱[cite: 7]。

👉 **(C) 【上下文組合切入】** 檢索（Retrieval）出最相關的原始文本片段後，連同客人的提問一起打包餵給 LLM，讓模型結合上下文生成最正確的回答（Generation）[cite: 7]。

二、 Summary（總結）

請依影片內容整理：文件切片、Embedding 向量化、檢索比對到生成回答的 RAG 完整流程，說明它如何讓本地 AI 成為可靠的商店客服。[cite: 7]

💬 卡住時問AI老師
引導：請從文件切塊、向量轉換、相似度檢索以及結合生成四個階段來思考[cite: 7]。
👉 點擊帶入句型範本：「我學到 RAG 架構先將商店文件進行 Chunk 切片與 Embedding 向量化。當顧客提問時，系統會透過 Retrieval 檢索出最相關的內容，最後交給本地 LLM 結合上下文進行 Generation 生成，避免 AI 產生幻覺。」[cite: 7]

三、 Question（提問）

請針對 Chunk 切塊大小設定、向量資料庫檢索或本地模型運算效能提出一個問題。[cite: 7]

💬 卡住時問AI老師
引導：想想看如果 Chunk 切得太大或太小，對 AI 檢索的準確度會有哪些影響？或者是本地 GPU 記憶體不足時該怎麼辦？[cite: 7]
👉 點擊帶入問句範本：「老師，在設定文件的 Chunk 切塊大小（Chunk Size）時，如果切得太大或太小，對 RAG 知識庫回答客服問題的精確度會有什麼影響？」[cite: 7]
